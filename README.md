# Glitterdomme local demo

Open `dist/index.html` in a browser. The four pages work from local files without installing dependencies. The Google Form requires an internet connection.

Home copy lives in `dist/index.html`. About and Services placeholders live in `dist/about.html` and `dist/services.html`.

The Session Request page embeds the live Google Form. To change forms, update both the iframe's `src` and the direct link in `dist/session.html`.

The contents of `dist` are ready to serve with any static file host.
